Help

An overview of how to configure and use matrix³.

You can use this extension to control the permissions of websites. For example, enabling sandbox features, disabling scripts, stylesheets, and fonts, and choosing which third parties can provide subresources.

The first thing you probably want to do is choose a default policy in the Options page.

Report

This is the primary page for interacting with matrix³. It lets you control the permissions of the active website. If the page embeds frames from other origins, each origin appears as a tab above the table.

Session and Dynamic Rules

Toggling a checkbox in the Report page creates a temporary session rule that lasts until you close the browser. Committing it creates a dynamic rule that persists across browser restarts:

  • Commit: Save the session rule as a persistent dynamic rule.
  • Uncommit: Demote a dynamic rule back to a temporary session rule.
  • Abandon: Discard session changes and restore the saved dynamic rule.
  • Reset: Remove all session and dynamic rules for the host.
  • Reload: Reload the tab to apply rule changes.

Violations

Blocked resources and actions are highlighted in orange. Enable the needed checkboxes, then click Reload to test. When you are happy with the settings, you can Commit them to make them permanent.

Sandbox Directives

Enabling the sandbox runs the document in an isolated origin and blocks scripts, forms, popups, downloads, and navigations unless selectively allowed. Cookies and storage require Allow Same Origin.

Server Suggested Policy

Shows the policy sent by the server for the current origin. Accept replaces your selection with the server's policy; Merge adds the server's sources to your selection. Nonces and hashes are imported unchecked so 'unsafe-inline' remains effective unless you enable them manually.

Rules

The Rules page lists all active dynamic rules, session rules, and static rulesets across all websites. Use Filter to search by host or directive, and select rules to Remove, Commit, or Reset them.

Groups

A group is a reusable bundle of sources and directives (such as common CDNs or embed hosts). Configure groups in the Groups page, then select one in the Report page and click Apply to enable its rules for the current host.

Sources and directives checked in the Ignore group (or all directives if default-src is checked) are hidden from violation reports.

Options

Default Policy Strictness

Sets the baseline policy in the Options page for sites without custom rules:

  • Permissive: Nothing is blocked by default; restrict sites individually in the Report page.
  • First Party: Allows first-party resources and third-party images, styles, and fonts. Blocks third-party scripts.
  • Sandbox + Scripts: Sandboxes every document in an isolated origin, allowing only scripts and forms. Cookies require Allow Same Origin.
  • Sandbox: Sandboxes every document with no exceptions; only static content works by default.
  • Strict: Blocks everything (default-src 'none') except first-party styles and images.

Always Show Advanced Directives

Rarely used directives (child-src, manifest-src, object-src) and advanced sandbox flags are hidden in the Report and Groups pages unless checked or triggered by a violation. Enable this to always show them.

Show Icon Badges

Displays a red ! badge on the toolbar icon when the active tab reports a CSP violation.

Confirm Actions

Asks for confirmation before destructive actions such as resetting rules or deleting groups.

Unregister Service Workers on Reset

Automatically unregisters service workers for the selected host when clicking Reset, preventing cached workers from bypassing stricter rules.

Default Scope

Groups rules and origin tabs either by registrable Domain (e.g., example.com, including subdomains) or by exact Host (e.g., sub.example.com).

Export

In the Export page, Download saves your dynamic rules, groups, and options to a JSON file, and Import restores them.

Sync

When signed into Chrome, Push and Pull merge your persistent dynamic rules with cloud storage across devices. Session rules remain local.
